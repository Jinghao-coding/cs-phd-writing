# 中文表达与语义检查

改写说明（2026-09-05）：重新组织两个上游的语言规则，新增中文句法与含义核对。来源及修改见 [上游改写记录](upstream-adaptation.md)。

适用于中文正文、摘要、章节导语和英文论文转写。目标是让技术含义一次读懂。以下例句为构造的语言示例，不是任何论文的实验事实。

## 从句子关系开始

阅读句子及必要的前后文，明确：研究对象、动作或判断、动作对象、适用条件、结果以及证据来源。检查时优先用最小改动修正实质问题。

逐句审阅时，先完成三步诊断，再用下表检查条件、比较、否定等细节：

1. **辨明主体与角色。** 找出句子的主要动作或判断，以及各分句中实际执行动作、承受动作或具有某种性质的对象。方法、系统、实验与实验结果的角色要与上下文相符；“实验结果表明性能提高”与“实验结果提高了性能”表达不同关系。被动句的语法主语可以是动作对象，定义句和“算法收敛”等句子也应按其语义正常处理。
2. **核对动作与对象。** 检查谓语、宾语及所指指标是否匹配，必要时恢复被名词结构掩盖的动作。搭配应结合具体含义判断；“降低平均响应时间”不必一律替换。语义完整且谓语本来无需宾语时，不为凑齐主谓宾形式补宾语；真正缺失必要对象时仍需修正。修改时保持动作方向、作用范围与指标定义。
3. **追踪指代与省略。** 遇到“其、该方法、这、上述”或省略主体时，结合语义、话题和作用范围寻找可能指向，不能自动选择最近的技术对象。上下文能够唯一确定时保留；存在歧义且材料能确定归属时补出名称；材料本身无法确定时，在正文之外记录待核，不猜选对象。

诊断过程服务于修改判断。只报告实际问题及必要依据，不要求把每个合格句子的检查过程逐项输出。

| 检查项 | 判断方式 | 常见处理 |
| --- | --- | --- |
| 主谓搭配 | 主语能否完成该动作或具有该性质 | 区分方法、系统、实验与实验结果各自承担的动作 |
| 动宾搭配 | 谓语与宾语的含义是否匹配 | 如“增加效率”通常应为“提高效率”；仍需核对效率定义 |
| 主语切换 | 连续分句是否仍指同一主体 | 必要时补主语，避免算法、资源、任务混成同一主体 |
| 指代 | “该方法、其、这、上述”是否唯一且明确 | 写出所指对象，或调整位置 |
| 修饰范围 | 限定的是对象、条件还是整个结论 | 移动定语、状语；不扩大适用范围 |
| 并列与比较 | 并列项是否同层次，比较对象和指标是否相同 | 明确比较双方及基准，避免把方法与指标相比 |
| 因果与条件 | 原文证据支持因果、相关、时序还是条件成立 | 保留原有关系，不把相继出现写成导致 |
| 否定与量词 | “部分、所有、至少、仅、不、未”等是否改变范围 | 按原意保留，发生改动时核对来源 |

例如，“实验结果降低了调度开销”把结果写成行动主体；在材料确实支持降低开销时，可写为“实验结果表明，该方法降低了调度开销”。若没有这项证据，不能只修语法后保留降低开销的断言。

中文省略主语并不自动构成语病。“本章介绍了实验平台。随后给出了测试配置。”在上下文清楚时可以保留。仅因句子以“通过、采用、针对”开头而判错，会产生误报。

### 何时复核省略与指代

以下情形触发上下文复核，不直接判定语病：

- 连续省略期间引入了新的动作主体，或话题已经切换。
- 同一上下文中有多个对象能合理承担后续动作，结果或贡献的归属可能因此改变。
- 指代距离变长、跨段落，或中间插入了对照方法及其他实验的说明。
- 后续动作、执行阶段或实验条件发生变化，需要重新确认主体及适用范围。

复核时区分“出现多个技术对象”与“存在多个合理指向”。明确的承前关系可以跨句或跨段保留；段首是否重述主体按可读性决定，不设连续三句、同段两个对象等硬性阈值。找不到可恢复的主体，或多个合理指向无法通过上下文消歧时，再依据材料补明；材料不足则保留待核记录。

### 最小对照示例

以下前提和例句均为构造材料，不属于任何真实论文。动作归属须有前提支持。

| 已知前提与原句 | 修改或保留 | 原因 |
| --- | --- | --- |
| 正文尚未说明两者机制；材料记载 A 逐个处理任务，B 批量处理。原句：“方法 A 与方法 B 使用相同输入。该方法每轮处理一个任务。” | “方法 A 与方法 B 使用相同输入。方法 A 每轮处理一个任务。” | 正文中的“该方法”有两个候选；依据材料明确为 A，不能按距离选 B |
| 预测器 P 提供需求估计，调度器 S 根据该估计选择节点。原句：“预测器 P 将需求估计传给调度器 S 后，选择执行节点。” | “预测器 P 将需求估计传给调度器 S，调度器 S 据此选择执行节点。” | 动作主体发生切换，省略会将选择节点错误归给预测器 |
| 调度器负责选择与记录。原句：“调度器根据任务需求选择节点。随后记录分配结果。” | 保留原句 | 虽出现任务、节点等对象，后续主体仍明确是调度器，不需要重复补主语 |

## 长句与段落

- 以信息关系决定是否拆句。一个句子同时挤入背景、方法、数值、解释和贡献时，按论证功能拆开。
- 长句若主干清楚、条件完整，可以保留；短句也可能有歧义。没有通用的字数上限或句长均匀度目标。
- 一段围绕一个中心问题展开，提供必要证据和解释。不要把每个短句另起一段，也不强制每段四句话。
- 需要进一步组织问题、方法、证明或实验分析时，按 [段落功能](paragraph-functions.md) 选择相应论证功能。检查套话与空泛分析时，参照 [学术表述检查](prose-quality.md)。
- “因此、然而、同时、此外”等连接词有真实逻辑作用时保留。删除的是空泛或错误连接，不是正常词语。
- 章节导引允许简洁说明组织关系，具体项目要求的“论文组织结构”节正常保留。

## 术语与词汇

1. 先查作者已有定义、领域语境和项目术语表，再决定译名。英文相同不一定概念相同，中文近义不一定可以替换。
2. 固定技术概念不为避免重复而轮换名称。普通叙述可以自然变化，但“吞吐率、利用率、效率”等指标不可混用。
3. 出现陌生组合词时，找定义或来源。缺少依据时列为术语待核，提出基于实际机制的解释性表达，不能擅自宣称它是公认术语。
4. 作者已明确提出的新概念可以保留，须有定义、对象及与相邻概念的区别。不得将“不能编造词汇”解释成禁止合法的新方法命名。
5. 没有可靠中文译名时，可保留英文并解释含义；首现、缩略语及后续写法遵循项目规范。

## 防御性表述

检查句子是在讲研究，还是在预先回应想象中的质疑。后者如“为避免读者误解”“需要特别强调”“这并非简单叠加”“不能认为本研究没有价值”，通常应删去或改成具体技术说明。

处理顺序：

1. 去掉向评审或读者辩护的开场。
2. 判断剩余部分是否提供真实信息：研究对象、机制、实验条件、适用范围或证据。
3. 有信息就直接表达；没有信息就删去。
4. 对正确理解当前结果不可缺少的限制，就地保留。一般性研究局限放到相应讨论部分，避免重复附在每个结果之后。

“在测试负载下，平均等待时间减少”中的测试范围不是防御性语言。“由式（3）与容量约束得到可行域”是数学推导；证明、推导、反例、设计取舍和消融分析不能因含有“由此、因为、但是”被删掉。

## 事实强度与改写核对

- 保留原文可支持的强度，不能为追求流畅把“可能相关”改成“导致”，把“未观察到差异”改成“完全一致”。
- 有充分证据的结果直接陈述，不习惯性追加“初步、一定程度上、可能有一定参考价值”。
- 发现夸大事实时，根据证据作实质更正，并说明更正；不能以“保持原意”为由保留已知错误。
- 检查改写前后：谁、对谁、做什么、何时何地、在哪些条件下、比较什么、数值多少、确定程度。逐项关注发生变化的部分，不必把这份内部检查表逐句打印给用户。

## 英文论文转写

- 先理解方法和证据，再按中文博士论文的论证顺序写作；避免逐句复制英文长定语和抽象名词结构。
- 按实际范围处理 we/this paper/our approach：整篇博士论文、当前章、具体方法各有对应主体，不机械全替换为“本文”。
- 删除原论文的宣传性包装，保留其研究条件与证据；目的、预期用途不能写成已测得的收益。
- 数字、单位、比较基准和时态含义须与选定版本一致。译文出现新实验或新因果解释时，返回证据检查。
