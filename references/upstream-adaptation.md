## 修正的上游限制

- 通用规则不继承某校格式、作者导师意见、固定绪论下限、固定章数或强制递进关系。
- 正常连接词、人称和承前省略根据上下文与项目规范判断，不设机械禁词表。
- 保留数学推导、证明、必要的研究条件以及有实际作用的章间导引。
- 量化陈述必须有数据；不将上游示例数字用作真实结果。精确动词替换也要核对是否真的做过相应分析。
- 审阅不必逐次重建全部事实表，不要求每次确认已有信息，不自动改整篇论文。

## 新增内容

- 中文句法与语义关系的逐项检查，以及改写前后事实含义核对。
- 词汇来源、合法新概念、译名和技术指标的处理规则。
- 对注释旧稿、误差/准确率、百分比/百分点、仿真/实测及投稿状态的事实检查。
- 面向不同学校、学科和个人偏好的项目配置约定。
- LaTeX/Word/PDF 的范围保护、材料依赖与同步边界。
- 使用合成案例检验事实错误、语言误报、范围保护及跨项目隔离；见 `evals/`。
- 多篇英文论文到中文学位论文的组织转换，包括版本归并、成果与章节对应、论证重组和跨稿证据检查。
- 按运行环境选择的 PDF、DOCX、LaTeX 工程和粘贴文本读取流程；保留上游按章阅读思路，取消固定工具名与固定页数限制。
- Codex 与 Claude Code 共用的安装说明、可复制的项目配置模板，以及版本发布与更新说明。
- 将文献综合、研究设计、方法结果讨论、文档对象和提交完整性检查整理为可按需读取的任务指南。
- 将上游段落功能思路整理为独立的 `paragraph-functions.md`，按计算机论文的研究对象重排为 24 类，补充算法、数学证明、实现、消融、开销及多成果综合；不机械要求复用上游的全部 27 类或段落顺序。
- `language_style.md` 的风格规则与 `forbidden_patterns.md` 的复核线索，分别整合到中文表达和学术表述检查中。核心原则是核查实际含义及证据，不将正常词语或句式设为禁用项。
