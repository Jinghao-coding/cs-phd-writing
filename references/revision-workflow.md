# 上下文修订与技术语义核对

用于纠错、润色、压缩、重组、英中转写和技术更正。句法细节见[中文表达](chinese-expression.md)，段落信息组织见[衔接与转写](cohesion-and-translation.md)。只读本次涉及的部分，不把单句修改变成全文审计。

## 先判断需要哪种修改

| 意图 | 默认动作与边界 |
| --- | --- |
| 纠错 | 修复确定的语病、错字和歧义；保留成立的表达 |
| 润色 | 在事实不变时改善可读性；正常长句、被动句、承前省略和技术词重复可以保留 |
| 压缩 | 删除重复和可恢复的信息；保留条件、否定、比较对象与推导所需步骤 |
| 重组 | 在指定范围内调整信息顺序、拆合句段；检查移动后的定义、引用与论证依赖 |
| 补充论证 | 从已有材料补足理解缺口；拟议解释、所需新实验和新增事实分开处理 |
| 技术更正 | 用可定位证据纠正科学含义；交付时简述依据，不能伪装成普通润色 |

遵循用户已指定的意图。对“润色”默认保持含义和局部范围；仅当歧义会影响实质判断时询问。先完成可以确定的部分。多轮修订沿用已接受的术语与决定，问题解决后停止，不为每轮产生差异而反复换词。

## 读取足够的上下文

先看目标段、相邻段、直接相关的定义、算法或图表；遇到一个具体疑点，再沿来源扩读。例如“释放缓存”应核对其对象是显存页、主存副本还是逻辑状态。不要从领域常识推定当前实现具有某项能力。

整节审阅可做反向提纲：为每段标出主要判断、支撑材料以及对下一段的作用，检查证据是否支持判断、判断是否服务本节问题。简单修改不必把提纲输出给用户。机制解释按读者理解需要补足概念；不固定摘要句数、段落数量、第一页图或章节篇幅。

## 问题分类与修复完成条件

区分：确定错误、上下文歧义、论证缺口、可选风格。对实质问题给出位置、影响和完成条件，例如“‘其’同时可能指模型与实例；改后须能唯一确定被卸载的是实例”。无需修改的文本可以直接保留。建议不能只写“更学术”“更高级”或“减少AI味”。

## 改写前后的语义核对

按实际风险核对下列项目。短句可直接心中对照；多段重写、数字密集或技术更正时保留简短对照记录。

| 对象 | 核对问题 |
| --- | --- |
| 实体与粒度 | 请求、任务、作业、工作流、模型与实例是否仍指同一对象？ |
| 主体、动作、输入输出 | 谁估计、谁决策、谁执行？动作依据和产出是否改变？ |
| 状态与顺序 | 候选与已选、提交与完成、逻辑删除与物理回收是否混淆？ |
| 条件、量词与否定 | 至少/至多、任意/存在、且/或、仅当/当、不/可能的作用域是否保留？ |
| 数字与指标 | 单位、分母、聚合方式、最大/平均、百分比/百分点、降低/加速是否一致？ |
| 比较与适用范围 | 相对于谁、何种负载与配置？跨句后条件是否仍约束结论？ |
| 因果与证据强度 | 观测、推断、设计目标、已测结果、保证是否被互换？ |
| 来源与归属 | 引文是否仍支撑这句话？移动引文后是否错误支持了新增判断？ |
| 文档对象 | 公式、引用键、标签、宏参数与图表指代是否保持或同步更正？ |

保持含义不要求字面完全一致；“24 ms降至18 ms”可等价写成“减少6 ms”或“降低25%”，但要核算并保留基准。发现原文科学错误时以证据更正，记录原判断、依据位置和新判断；不能为了保持原句而保留错误。

来源定位按规模选用文件与段落、页码、图表或已有证据编号。重要结果可沿用项目现有“论断—证据”表；不强制为每句创建ID。跨摘要、正文、图题的数字冲突回到原始证据核对，不能只选择出现次数最多的版本。

## 交付与检查

先给用户需要的替换正文；技术更正和关键缺口放在正文外。局部改写检查受影响的引用和术语；涉及LaTeX结构才按项目要求构建。自动检查见[工具入口](language-tools.md)，实例与分项评价见[修订评估](../evals/revision-evaluation.md)。自动工具报告的差异需结合语义判断；语言流畅与事实正确分别评估。
