# 可合并到项目说明的片段

将适用条目合并到论文项目的 `AGENTS.md`（Codex）或 `CLAUDE.md`（Claude Code），保留原有项目约定；本文件不应整份覆盖已有项目说明。

- 中文博士学位论文写作、组织转换和审阅使用 `cs-phd-writing` 技能。
- 从当前论文项目读取 `docs/thesis-writing-profile.md`，按本次任务访问其中指向的学校规范、范文分析和研究材料。
- 个人资料与学校要求保存在论文项目中；不从技能安装路径推定论文项目或读取别人的配置。
- 多篇英文论文整合时利用已有成果索引，按问题建立成果与章节对应；保留事实、版本、本人贡献和原文定位。
