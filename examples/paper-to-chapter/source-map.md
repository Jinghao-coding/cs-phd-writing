# 新增内容的依据与性质

位置采用节标题和LaTeX标签，便于正文移动后更新；所有输入均属独立构造教学材料。

| 成稿位置 | 输入依据 | 性质与核对 |
| --- | --- | --- |
| 场景段“索引移除与读者访问” | inputs/paper.md；model.md第一段 | 类1：输入已有的生命周期说明，补回压缩段省略的困难 |
| 状态与安全条件，eq:reclaim-condition | model.md；algorithm.txt的check | 类1：共同条件、互斥假设与计数语义；不把或当成且 |
| “分别排除了不同的不安全状态” | model.md获取路径和计数完整性假设 | 类2：在明确模型内的安全解释，不外推为无锁实现证明 |
| 贯穿示例，2→1→0 | model.md给定初态；algorithm.txt | 类2：逐事件推导，未假造时间或测量 |
| 两条路径均调用检查、释放一次 | algorithm.txt及model.md | 类1：补充短文省略的控制流及状态约束 |
| O(1)/O(q)与不同触发频率 | model.md代价模型 | 类1及类2：给定单次成本，并推导不能直接比较总成本；不声称实测更快 |
| 与前章关系 | project/background.tex；model.md末段 | 类1：复用概念，通过章引用避免完整重复定义；无调用/联合实验 |
| tab:synthetic-space及W/V结果段 | results.csv；results-notes.md | 类1：合成值；类2：28%降低与10%增加的算术核算 |
| 小结 | 上述各节 | 汇总模型条件和实际给定结果，不新增事实 |

类3待验证判断仅保存在 [review.md](review.md)：竞争成本、真实空间收益、V的成因、联合部署。这些需要新实现或实验，未补入既成结果。这里只示范一种章节组织，不为其他研究设置固定节数。
