## 已确认的章节安排

记录必须保留或避免的安排、题目是否可调整、哪些成果仅作前期基础，以及仍待讨论的部分。不要由论文数量推定章数。

## 未确认事项

只记录会影响判断的具体缺项；写作时先处理已有依据的部分。学校规范与偏好出现实质冲突时记录双方来源，不静默改写成一致。
